## 失败用例与根因（按阶段）

| 阶段 | 用例 | 现象 | 根因 |
|---|---|---|---|
| URL 提取 | DY-X3 无链接文本 | unknown_platform，0.17s | 文本中无 URL，符合预期 |
| 平台识别 | UNS-B3 YouTube 真实链接 | unknown_platform | 不支持的平台，提示明确，符合预期 |
| 平台识别 | UNS-B1/B2 B 站、微博 | unknown_platform | **前端平台表宣称支持，后端未实现**（KI-1） |
| 平台识别 | SEC-U1 元数据 IP | unknown_platform | 非平台域名，未发起抓取，符合预期 |
| 平台识别 | SEC-U2 userinfo 混淆 | 修复前进入抓取管道（extract_failed 4.08s）；修复后 unknown_platform | detect_platform 对整串 URL 正则匹配 → 已修复（FIX-1） |
| 内容提取 | DY-X1 无效短链 / DY-X2 不存在 ID / TT-X1 / XHS-X1 / KS-P1 | extract_failed | 链接无效或非内容页，管道各策略均无结果；错误结构正确，但无效与不存在共用同一错误码（KI-6） |
| 内容提取 | XHS-L1 小红书真实短链 | extract_failed 4.91s | 小红书匿名抓取被风控拦截，需登录态；本项目不绕过登录/访问控制（KI-2） |

## 三段成功率（分别统计）

- 解析成功：5 / 6 条真实内容链接（抖音视频、抖音图文、TikTok 各形态通过；小红书真实短链失败）
- 结果校验成功：5 / 5（全部成功用例的媒体经全量下载/魔数/编码校验，无 HTML 冒充视频、无空文件）
- 下载成功：5 / 5（视频附件下载 200 且文件名正确；图片、音乐均可完整获取；篡改/过期令牌正确返回 403 JSON）

## 平台结论

- **抖音**：视频（短链/文案/详情三种形态）与图文均可用，依赖备用解析服务。
- **TikTok**：详情链接可用（主路径）。
- **小红书**：当前不可用（平台登录墙/风控），界面应避免给用户过高预期。
- **快手**：平台识别与非内容链接拒绝行为正确；真实内容链接未覆盖，能力未知。
- **B 站 / 微博**：前端宣称支持但后端不支持，必须修正文案或下线宣称（KI-1）。

详细逐条数据见 `link-compatibility-results.json`。
